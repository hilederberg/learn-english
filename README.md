# לימוד אנגלית

אפליקציית PWA ללימוד אנגלית למתחילות, 20 דקות ביום. בלי שרת, בלי תלויות ובלי שלב build: קבצי HTML, CSS ו-JS רגילים.

## מה בפנים
- חזרות מרווחות (FSRS-4.5), חומר חדש בקבוצות של שניים, ביס דקדוק יומי, דיאלוגים ותרגול דיבור עם הקלטה והשוואה.
- עובדת בלי אינטרנט (service worker). ההתקדמות נשמרת בטלפון (IndexedDB), עם גיבוי ושחזור לקובץ.
- עברית מימין לשמאל, מצב כהה אוטומטי, תנועה חלקה (ומכבדת "הפחתת תנועה").

## הרצה מקומית
```
npm run serve        # http://localhost:8080
npm test             # בדיקות יחידה (מנוע הלמידה, FSRS, גיבוי)
npm run sw           # יצירת sw.js מחדש (חובה אחרי שינוי בקבצים)
```

## פריסה ל-GitHub Pages
1. ליצור repo ולדחוף ל-`main`.
2. Settings ← Pages ← Source: **GitHub Actions**.
3. ה-workflow ב-`.github/workflows/pages.yml` מריץ בדיקות, מייצר `sw.js` ומפרסם.
הכתובת תהיה `https://<user>.github.io/<repo>/`. כל הנתיבים באפליקציה יחסיים, אז זה עובד גם בתת-נתיב.

## קול ההקראה
כל משפט באנגלית מוקלט מראש בקול נוירוני טבעי (Ava, ובדיאלוגים גם Andrew) ונשמר ב-`audio/`, כך שההקראה טבעית בכל טלפון וגם בלי אינטרנט. משפט בלי הקלטה מוקרא בקול של המכשיר.
אחרי כל שינוי בתוכן:
```
pip install edge-tts           # פעם אחת
python tools/make-audio.py     # מקליט רק משפטים חדשים, מוחק ישנים
npm test && npm run sw
```
`npm test` נכשל אם חסרה הקלטה למשפט כלשהו.

## הוספת יחידה
1. להוסיף קובץ `content/units/unit-04.json` באותו מבנה של הקיימים.
2. ב-`content/units.json` להפוך את היחידה ל-`"open": true`.
3. `python tools/make-audio.py` (הקלטות), `npm test` (בודק תקינות תוכן והקלטות) ואז `npm run sw`.

## מגבלות ידועות
- התראות יומיות אי אפשר בלי שרת. בהגדרות יש הסבר איך לקבוע תזכורת באייפון.
- הקראה משתמשת בקולות המערכת. באייפון כדאי להוריד קול משופר: הגדרות ← נגישות ← תוכן מדובר ← קולות ← English.
- אין זיהוי דיבור אוטומטי (לא נתמך ב-PWA באייפון). ההשוואה היא בשמיעה עצמית.
